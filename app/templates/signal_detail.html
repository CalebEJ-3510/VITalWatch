Data-quality caveats

  • {{ s.cases }} case{{ '' if s.cases == 1 else 's' }} is a small numerator — treat the ranking as a triage order, nothing more.
  • {{ s.serious }} serious, {{ s.severe }} severe of those cases — seriousness, severity and signal strength are different facts.
  • Coding is against a curated demonstration vocabulary, not MedDRA — term granularity is coarser.
  • No chi-square or confidence interval is reported at these volumes; both would be noise.
{% call note('Why there is no "open investigation" button here') %}

The earlier investigation-board feature was removed from this codebase; there is no case board left to link to, and a button that silently routed every signal to one hardcoded demonstration case is exactly the dishonesty this redesign exists to remove. The investigation workflow that genuinely exists is the governance escalation: raise a safety concern, and the review package (clock, structured response, reviewer disposition, leadership decision, audit) is the record of the investigation.
